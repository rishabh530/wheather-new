# 🌤️ Weather App

A simple responsive Weather App built with HTML, CSS and JavaScript.

## Features

- Search weather by city
- Current temperature
- Weather condition
- Humidity
- Wind speed
- Feels-like temperature
- Responsive design
- OpenWeatherMap API integration

## Tech Stack

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## Setup

1. Create an account on OpenWeatherMap.
2. Get an API key.
3. Open `script.js`.
4. Replace:

```js
const API_KEY = "e260c3146fe0bf6128c1df492b48e1ef";
```

with your API key.

5. Open `index.html` in your browser.

## Important

Do not upload a real API key to a public GitHub repository. For a production application, keep API credentials on a backend/server or use a suitable public-client setup.
